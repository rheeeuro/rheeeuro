주로 **React, Next.js, TypeScript**를 사용해 웹 서비스를 개발하고 있습니다.

기능을 구현하는 것에서 끝내기보다
실제로 서비스를 운영하고, 데이터를 확인하고, 문제를 발견해 개선하는 과정에 관심이 많습니다.

최근에는 익숙한 프론트엔드 개발 영역을 넘어
**Three.js, WebGL, WebGPU** 같은 인터랙티브 웹 기술도 조금씩 공부하고 있습니다.
